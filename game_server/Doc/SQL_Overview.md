## 三、SQL文件使用说明

### 执行顺序
1. 首先执行 `create_db.sql` 创建主数据库和核心表
2. 执行 `create_config_db.sql` 创建配置数据库和配置表
3. 执行 `insert_config_data.sql` 插入配置数据
4. 执行 `create_player_data_tables.sql` 创建玩家数据表

### 注意事项
- 所有SQL脚本都使用 `utf8mb4` 字符集，确保支持中文
- 建议在测试环境先执行，确认无误后再在生产环境执行
- 定期备份数据库，防止数据丢失
- 遵循数据库设计规范，避免冗余字段和表
